# Basel Climate & DNN Analysis

This repository contains **two independent projects**:

1. **Basal Climate Analysis** — Machine-learning workflow for processing Basel climate data, performing feature selection, hyperparameter optimisation, clustering, and model evaluation.  
2. **Image Processing Using DNN** — A collection of deep-neural-network (DNN) experiments for image classification, feature extraction, and model comparisons.

Both projects are standalone, but share a common environment defined in `requirements.txt`.

---

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/GitSentinel/basel-climate-dnn-analysis.git
cd basel-climate-dnn-analysis
```

## 2. Create & Activate Virtual Environment
### Windows
```bash
python -m venv venv
venv\Scripts\activate
```

### MacOS/Linux
```bash
python3 -m venv venv
source venv/bin/activate
```
## 3. Install Dependencies
```bash
pip install -r requirements.txt
```

# 🌦️ Basal Climate Analysis — How to Run
The analysis must be executed in order, because the second notebook uses outputs generated by the first.

## Step 1 - Run Hyperparameter Search Notebook
File:
```bash
basal_climate/hyperparameter_search.ipynb
```

The notebook performs:
- Scaling & preprocessing
- Variance Thresholding
- PCA reduction
- Hyperparameter optimisation for:
  - corr_threshold
  - variance_threshold
  - pca_variance
  - contamination
  - scaler_type
- Saves best parameters & processed dataset to the output/ folder

Run all cells, and ensure the output/ directory contains:
```bash
best_params.json
processed_dataset.csv
pca_components.npy
...
```

## Step 2 — Run Model & Clustering Notebook
File:
```bash
basal_climate/final_model.ipynb
```
The notebook performs:
- Loads outputs from Step 1
- Performs model comparisons:
  - K-Means
  - DBSCAN
  - Gaussian Mixture Model
- Computes internal cluster metrics:
  - Silhouette Score
  - Davies–Bouldin Index
  - Calinski–Harabasz Score
- Generates visualisations
- Outputs final results to output/

After running all cells, you’ll find:
```bash
cluster_results.csv
metrics_summary.json
plots/
```

# 🧠 DNN Image Processing — How to Run
The DNN project allows you to run any notebook independently, in any order.
Each model category is self-contained.

Inside `image_processing_using_dnn/`, you’ll find folders such as:
```bash
EfficientNet/
RegNet/
DINOv2/
feature_extraction/
```

Each folder typically contains:
- A notebook (`.ipynb`)
- Dataset instructions
- Model training / inference code

## Steps to run a DNN notebook
1. Navigate to the desired folder:
```bash
cd image_processing_using_dnn/<ModelName>/ 
```
2. Open the notebook:
```bash
jupyter notebook
```
3. Ensure your dataset is placed in:
```bash
image_processing_using_dnn/datasets/ 
```
using ImageFolder structure:
```bash
datasets/
    class1/
        img1.jpg
        img2.jpg
    class2/
        img3.jpg
        img4.jpg

```
4. Run all cells to:
    - Train
    - Validate
    - Test 
    - Extract Features
    - Export CSV embeddings 
    - Evaluate accuracy/loss curves

Each notebook is independent and will run without relying on any other notebook.
